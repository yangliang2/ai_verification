Description

Steps to replicate the issue (include links if applicable):

  • Open the Wikipedia Android app.
  • Navigate to Saved.
  • Tap on Discover inside the Saved section.

What happens?:
The Discover section takes a long time to open and sometimes keeps loading without displaying content. The user reports that the issue occurs almost every time. After waiting or trying again multiple times, the Discover page may eventually load.

What should have happened instead?:
The Discover section should open normally and display the recommended content without long loading times.

Software version (on Special:Version page; skip for WMF-hosted wikis like Wikipedia):
App version: 50567-r-2026-02-04
Device: Redmi XIG05
Android SDK: 36

Other information (browser name/version, screenshots, etc.):
Issue occurs on both Wi-Fi and mobile data.

Clearing the app cache did not resolve the problem.

Restarting the device did not resolve the problem.

The user has approximately 273 saved articles.

If the user waits and retries multiple times, the Discover section may eventually load.
