Description

Steps to replicate the issue (include links if applicable):

  • Play the Which Came First game in French
  • Navigate to the game archive, scroll to December 26, 2025
  • Play the game
  • When the error appears, attempt to tap Go Back or 'X', and attempt to start the game again

What happens?:
An error occurs that cannot be cleared. The error reappears if the user attempts to start the game again. At this point, the user is stuck. Any attempt to reenter the game results in the error reappearing. Restarting the app does not clear the error.

What should have happened instead?:
No error should occur, but if one does, the user should be able to clear it and continue using the feature.

Software version (on Special:Version page; skip for WMF-hosted wikis like Wikipedia):
Tested on 50567-r-2026-02-04 on OnePlus 8 on Android 13, and Pixel 6 on Android 16.

Reported by a user; thanks, @ARamadan-WMF, for flagging this.
