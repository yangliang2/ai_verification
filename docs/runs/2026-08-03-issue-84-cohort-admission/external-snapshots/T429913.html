Description

Steps to replicate the issue (include links if applicable):
A user reports that the Wikipedia Android app continues to consume approximately 4.39 GB of user data even after all offline saved articles have been removed. Clearing the app cache and restarting the app did not reduce the reported storage usage.

  • Download a large number of articles for offline reading.
  • Remove all offline saved articles.
  • Clear the app cache.
  • Restart the app.
  • Check the app's storage usage in settings.

What happens?:
The app continues to report approximately 4.39 GB of user data, despite the offline articles having been removed.

What should have happened instead?:
Storage usage should decrease after offline content has been removed, and any associated files should be cleaned up appropriately.
