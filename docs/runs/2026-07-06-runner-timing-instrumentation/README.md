## Implementation surface

From `git show --stat --name-only --oneline 5e0057e`:

```text
5e0057e #11 runner: per-phase timing instrumentation in verdict.json

```

Implementation summary:

- `src/aiverify/runner/journey.py` times journey, checkpoint, and system-event
  phases in execution order.
- `src/aiverify/runner/cli.py` writes `started_at`, `finished_at`,
  `total_seconds`, and per-phase timing into `verdict.json`.
- `tests/runner/test_journey.py` covers the timing sequence, kinds, populated
  durations, and event name.
- `docs/M1-goldset-report.md` records that runner-native timing supersedes
  shell-level wall-clock approximation.
